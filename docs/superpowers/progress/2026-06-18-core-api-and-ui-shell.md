### Deviations from Plan

- **`<BrowserRouter>` location**: plan's example shows it inside App.tsx, but moved it to `main.tsx` to enable `MemoryRouter` in tests. This is the canonical pattern for testable React Router apps. Tests wrap App in `MemoryRouter` to drive URLs deterministically.
- **`currentView` state**: kept temporarily so the existing Sidebar/Header still receive their `currentView`/`setView` props (active-state styling). Task 22 removes the state and migrates the Sidebar to React Router `<Link>` components. This is the 6-step migration the plan describes.
