## Strict TDD

- **Modo**: ENABLED (`strict_tdd: true`)
- **Regla de hierro**: NO producción code sin failing test primero
- **RED → GREEN → REFACTOR** para cada tarea Go/TypeScript
- **Go test**: `go test ./...`
- **Frontend test**: `cd web && npx vitest run`
- **Race detector**: No disponible en Windows sin CGO (usar CI/Linux)

## Reglas de commit

- **Conventional commits**: `feat:`, `fix:`, `test:`, `chore:`, `docs:`, `refactor:`, `ci:`
- **Scope opcional**: `feat(api):`, `fix(web):`
- **Sin AI attribution**: No `Co-Authored-By:`, no "Generated by"
- **Work-unit commits**: un cambio lógico por commit
- **Size exception**: incluir `(size exception: NNN lines)` cuando >400 líneas

## Code style

- **Inglés** en código, identificadores, funciones, comentarios, UI copy, errores
- **Español rioplatense** solo en conversación con el usuario
- Cross-platform: Windows + Linux
- Sin `panic` en producción (usar `gin.Recovery()`)
